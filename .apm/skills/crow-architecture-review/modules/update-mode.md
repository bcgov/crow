# Architecture Update Mode

Use this module only when the classified output document already exists.

1. Read the existing document completely before editing.
2. Repeat the repository-inspection passes against current source.
3. Preserve accurate manually curated prose and links.
4. Update stale versions, dependencies, topology, integrations, and implementation status with current evidence.
5. Add newly required template sections without rewriting unrelated sections.
6. Retain removed components as historical entries when needed for auditability and record the removal in revision history.
7. Increment the document revision and add a dated summary of material changes.
8. Report what changed, what was preserved, and what remains unknown or requires manual review.

Do not replace the existing document wholesale merely because the current template wording differs.
